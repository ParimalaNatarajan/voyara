# ✈️ VOYARA — Luxury Travel Website

**Discover the world. Experience extraordinary journeys.**

VOYARA is a premium travel website designed to inspire travellers to explore beautiful destinations and discover unforgettable travel experiences. It features an elegant interface, immersive visuals, and a refined luxury-inspired design.

## 🌐 Live Demo

**[Visit VOYARA →](https://voyara-git-main-parimala3138-8065.vercel.app/)**

## 📸 About the Project

VOYARA is a frontend web development project focused on creating a visually engaging and responsive luxury travel experience.

The website combines modern web technologies with an elegant design approach to showcase destinations, travel experiences, and the brand's identity.

## ✨ Features

- **Luxury Landing Page** — Elegant hero section with immersive visuals.
- **Popular Destinations** — Explore curated travel destinations.
- **Travel Experiences** — Discover unique travel experiences.
- **Brand Story** — Dedicated section introducing the VOYARA philosophy.
- **Travel Gallery** — Visual showcase of travel inspiration.
- **Testimonials** — Traveller feedback and experiences.
- **Enquiry Section** — Interface for travel enquiries.
- **Interactive UI** — Smooth animations and interactive elements.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ParimalaNatarajan/voyara.git
   ```

2. Navigate to the project directory:

   ```bash
   cd voyara
   ```

3. Open `index.html` in your browser.

No additional dependencies or build tools are required.
